# 12_Visual_Catalog
- `index.html` → open on phone/desktop; sections link to `pages/*.html`.
- `ContactSheet_<section>.jpg`: labelled sheets (Asset ID, name, pack, format, tier).
- `renders/<ASSET_ID>.jpg`: LOCAL RENDER of the actual model file (three.js r160, headless Chromium, idle pose when available). Characters/creatures/animals are rendered per asset; environment/prop packs have ~6 sample renders each.
- `official_previews/`: creator-provided images (pack level) and `per_asset/` official thumbnails (Scitizia, Vuena, Poly Haven). These are not renders of the local file.
- No AI-generated images are used.

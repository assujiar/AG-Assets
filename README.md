# ARSIP-GANJIL-3D-ASSET-LIBRARY

Central, license-checked 3D asset library for Arsip Ganjil video production (Three.js / R3F / Remotion).

- **5005 unique models** (5031 production files), **4297 animation clips** read from the files, 54 rig families.
- 5029 of 5031 production files load in three.js r160 (GLTFLoader/FBXLoader/OBJLoader); the 2 failures are flagged Tier D.
- Licenses: CC0 throughout, plus a few CC BY community items (credit lines in `14_Codex_Integration/AssetLicenses.md`).

Start here:
1. `14_Codex_Integration/README_FOR_CODEX.md` — how to find, pick and load assets.
2. `14_Codex_Integration/ACQUISITION_SUMMARY.md` — counts per category, gaps.
